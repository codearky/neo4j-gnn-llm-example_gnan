# Extension of GNAN to Node Embedding Vectors

## Handling High-Dimensional Embeddings with Feature Groups

While the original GNAN formulation operates on individual node features where each feature $k$ is transformed by its own shape function $f_k$, many modern graph learning scenarios utilize pre-computed node embeddings from large language models or other representation learning methods. These embeddings are typically high-dimensional (e.g., 768 or 1536 dimensions) and encode semantic information about nodes in a distributed manner, where individual dimensions do not have interpretable meanings in isolation.

To address this challenge, we extend GNAN to support **feature groups** rather than treating each embedding dimension as a standalone feature. This extension maintains the interpretable-by-design philosophy of GNAN while enabling it to work effectively with modern embedding-based representations.

## Formulation with Feature Groups

Instead of defining separate shape functions for each of the $d$ individual features, we partition the feature space into $G$ groups, where each group $g \in \{1, \ldots, G\}$ contains a subset of feature indices $\mathcal{F}_g \subseteq \{1, \ldots, d\}$. In the common case of using a single embedding vector per node, we have $G=1$ and $\mathcal{F}_1 = \{1, \ldots, d\}$.

For each feature group $g$, we define a shape function $f_g(\mathbf{x}_g; \theta_g) : \mathbb{R}^{|\mathcal{F}_g|} \to \mathbb{R}$ that operates on the concatenated features within that group, where $\mathbf{x}_g = [x_{k_1}, \ldots, x_{k_{|\mathcal{F}_g|}}]$ for $k_i \in \mathcal{F}_g$.

The node representation for node $i$ is then computed as:

$$[\mathbf{h}_i]_g = \sum_{j=1}^{N} \frac{1}{\#\text{dist}_i(j, i)} \cdot \rho\left(\frac{1}{1 + \text{dist}(j, i)}\right) \cdot f_g\left([\mathbf{x}_j]_{\mathcal{F}_g}\right)$$

where $[\mathbf{x}_j]_{\mathcal{F}_g}$ denotes the feature vector of node $j$ restricted to the indices in feature group $g$.

For graph-level prediction tasks, the final prediction is computed as:

$$\sigma\left(\sum_{g=1}^{G} \sum_{i=1}^{N} [\mathbf{h}_i]_g\right) = \sigma\left(\sum_{g=1}^{G} \sum_{j=1}^{N} f_g\left([\mathbf{x}_j]_{\mathcal{F}_g}\right) \sum_{i=1}^{N} \frac{1}{\#\text{dist}_i(j, i)} \cdot \rho\left(\frac{1}{1 + \text{dist}(j, i)}\right)\right)$$

## Implementation

We implemented this extension in PyTorch Geometric as `TensorGNAN`, which accepts a `feature_groups` parameter specifying the grouping of feature dimensions. The implementation supports:

1. **Flexible Feature Grouping**: Users can specify arbitrary partitions of the feature space, from treating all dimensions as a single group (for embedding vectors) to treating each dimension individually (recovering the original GNAN formulation).

2. **Efficient Tensor Operations**: The grouped computation is implemented using tensor operations that leverage GPU acceleration while maintaining the additive structure essential for interpretability.

3. **Node Importance Attribution**: Despite operating on grouped features, the model can still compute node-level importance scores by aggregating contributions across feature groups:

$$\text{importance}(j) = \sum_{g=1}^{G} f_g\left([\mathbf{x}_j]_{\mathcal{F}_g}\right) \sum_{i=1}^{N} \frac{1}{\#\text{dist}_i(j, i)} \cdot \rho\left(\frac{1}{1 + \text{dist}(j, i)}\right)$$

## Application to Knowledge Graph Question Answering

In our experiments on the STaRK-QA benchmark, we apply this extension to work with 1536-dimensional node embeddings generated by encoding node descriptions with a sentence transformer model. We configure GNAN with a single feature group containing all 1536 dimensions:

```python
gnn = TensorGNAN(
    in_channels=1536,
    hidden_channels=1536,
    out_channels=1536,
    n_layers=4,
    normalize_rho=True,
    feature_groups=[list(range(1536))],
)
```

This configuration treats the entire embedding vector as a single semantic unit, which is appropriate given that individual dimensions in the embedding space do not have standalone interpretations. The shape function $f_1$ learns a nonlinear transformation of the full embedding vector, while the distance function $\rho$ learns how to aggregate information from nodes at different graph distances.

## Interpretability with Feature Groups

While feature groups reduce the granularity of feature-level interpretability compared to individual features, the model remains interpretable at multiple levels:

1. **Global Distance Patterns**: The learned $\rho$ function can be visualized to understand how graph structure influences predictions (e.g., whether the model relies primarily on immediate neighbors or incorporates multi-hop information).

2. **Node-Level Importance**: The model provides exact node importance scores, identifying which entities in the knowledge graph are most influential for each prediction.

3. **Group-Level Contributions**: For configurations with multiple feature groups, the contribution of each group can be analyzed separately, enabling understanding of how different types of node information contribute to predictions.

This extension enables GNAN to leverage the representational power of modern pre-trained embeddings while maintaining its core advantage of providing interpretable, glass-box explanations of model predictions—a critical requirement for high-stakes applications where understanding model reasoning is as important as prediction accuracy.
